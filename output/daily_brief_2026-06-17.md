### Project 2: Agentic Earnings Intelligence System
**Pitch:** An AI research agent that reads every earnings call and 10-Q in your watchlist overnight and delivers a ranked briefing by morning — the way a junior analyst should, but faster and cheaper.

**Problem:** A single S&P 500 earnings season produces 500 transcripts in 3 weeks. LLMs hallucinate without RAG. Fix: RAG over SEC EDGAR filings + structured agent that extracts signals, flags guidance changes, scores sentiment with citations. MarketSenseAI demonstrated 8–18.9% excess returns using this pattern over 2023–2024.

**Stack:** Python + LangChain/LlamaIndex · SEC EDGAR API (free) · Earnings transcripts · OpenAI embeddings + Chroma (local) or Pinecone · Claude for synthesis

**Build time:** 5–8 days · **Difficulty:** MEDIUM–HARD

**Who cares:** Buy-side analysts, long/short equity funds, VCs running public market comps, investment management interviewers

**LinkedIn angle:** "Earnings season is 500 calls in 3 weeks. I built an AI agent that reads all of them overnight and delivers a cited briefing ranked by guidance surprises. The secret: RAG over SEC EDGAR + an agent that knows when to say 'I don't know'..."

### Project 3: Multi-Agent FX Carry Trade Signal Engine
