### 3. FX Risk Copilot — *HARD*
**Pitch:** "A senior risk officer in an API — macro regime to hedging recommendation in 30 seconds."

**Problem:** FX desks spend hours connecting macro regime shifts (rate differentials, PMI divergence, COT positioning) to position-level hedging decisions. The reasoning is structured and learnable; no tool closes the loop from live data to a decision-ready memo.

**Stack:** Claude Sonnet with extended tool use + sequential sub-agents (macro fetch → risk analysis → hedging strategy → executive memo), OANDA API for live FX rates, FRED (free), CFTC COT data (free), Supabase, React + Plotly dashboard.

**Build time:** 3–4 weeks to investor-grade demo | **Audience:** FX trading desks, corporate treasury teams, fintech startups building risk products, VCs evaluating finance-AI founders.

**LinkedIn angle:** "At Afterprime I saw how much time goes into connecting macro signals to hedging decisions.
